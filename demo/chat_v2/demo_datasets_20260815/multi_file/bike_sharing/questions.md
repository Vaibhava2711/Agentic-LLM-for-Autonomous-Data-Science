# UCI Bike Sharing Demo Questions

Upload and select `day.csv`, `hour.csv`, and `Readme.txt`.

## 1. Daily-hourly reconciliation

Do the two files report the same daily ride totals? If not, on which dates and for which user types do the main differences appear?

## 2. Annual growth

How much did bike-sharing usage grow in 2012 compared with 2011, and how did the growth differ between registered and casual users?

## 3. Working and non-working day peaks

At what times does bike-sharing usage peak on working and non-working days, and how do their daily usage patterns differ?

## 4. Weather and ride demand

How does bike-sharing usage vary with the weather? Which conditions have the highest and lowest ride volumes, and is there enough data for each comparison?
